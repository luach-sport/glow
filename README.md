# Glow — רקע חדש. כוח חדש.

אפליקציה לאנדרואיד שמחליפה לבד את הרקע של מסך הבית ומסך הנעילה, ושמה עליו משפט של מוטיבציה וחיזוק. עובדת בלי אינטרנט, בלי פרסומות ובלי הרשמה.

## הורדה

**[הורדת האפליקציה (glow.apk)](https://github.com/luach-sport/glow/releases/latest/download/glow.apk)**

הקישור תמיד מוביל לגרסה האחרונה. הסבר מלא: https://luach-sport.github.io/glow/

### התקנה בטלפון
1. פותחים את הקישור בטלפון ומורידים את הקובץ.
2. פותחים את הקובץ שירד. בפעם הראשונה הטלפון יבקש לאשר "התקנה ממקור לא ידוע". מאשרים.
3. בפתיחה הראשונה בוחרים איפה לשים את הרקע ומתי להחליף, ולוחצים "בואו נתחיל".

העדכונים הבאים נכנסים מתוך האפליקציה.

## מה יש באפליקציה
- **מסך הבית ומסך הנעילה:** אותו רקע לשניהם, או לכל אחד הגדרות משלו.
- **מתי מחליפים:** לפי זמן (5 דקות עד יום), בכל הדלקת מסך, לפי שעות היום, או בלחיצה – לתמונה ולמשפט בנפרד.
- **תמונות:** 50 תמונות מצוירות (נופים וצבעים, בלי אנשים), תמונות מהגלריה, מועדפות, ותמונות לפי שעות היום.
- **משפטים:** 180 משפטי מוטיבציה וחיזוק, משפטים משלך, ייבוא וייצוא, חיפוש ומועדפים.
- **עיצוב המשפט:** מיקום, גודל, צבע, גופן, פס רקע וצל.
- **חנות:** חבילות משפטים ותמונות בחינם, עם עדכון אוטומטי.
- **ווידג'ט**, היסטוריה וחזרה לרקע קודם, שיתוף כתמונה, מצב בהיר / כהה, שיתוף האפליקציה ופנייה למפתח.

עובד מאנדרואיד 6 (מסך הנעילה מאנדרואיד 7).
